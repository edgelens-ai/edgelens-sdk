# Framework Integrations

Test framework adapters built on top of `core/`. Each integration wraps the core client in framework-native idioms (fixtures, plugins, libraries).

| Subdir | Package | Framework | Status |
|---|---|---|---|
| `pytest/` | `edgelens-pytest` | pytest | Available |
| `playwright/` | `@edgelens/playwright-plugin` | Playwright | Available |
| `k6/` | `xk6-edgelens` | k6 | Source (build with `xk6`) |
| `robot/` | `edgelens-robot` | Robot Framework | Available |
| `cli/` | `edgelens-cli` | standalone | Available |
| `mcp/` | `edgelens-mcp` | MCP clients | Available |
